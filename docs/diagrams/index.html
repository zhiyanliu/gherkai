gherkai 架构图

gherkai 是一个 UI 自动化测试工具：用 Gherkin 写用例，由 AI 引擎在云端浏览器中执行。下面两张图是它的可交互架构图，可以缩放、聚焦单个组件、追踪一条路径；每张图的文字说明在仓库的技术文档中。

  • 执行与推进模型

    前台 run 与后台 submit、本机与云端两种后端组合出的四种运行方式下，由谁驱动执行、事件如何流转、worker 进程的退出如何被观察。

    文字说明：docs/internals/execution-and-reconciliation.md

  • 云端交付与 worker 身份

    官方基底镜像、你的 ECR 仓库、任务定义 revision、SSM 映射与默认指针之间的关系；gherkai deploy 的每一步改动哪一层；旧 revision 何时可以清理。

    文字说明：docs/internals/cloud-backend-carriers.md
