# 会员中心 需求说明

## 1. 背景

会员中心页向登录会员展示其当前等级与权益。页面以累计积分为输入（测试环境用地址参数 `points` 模拟）。

## 2. 功能需求

- **F1 等级展示**：页面显示会员当前的等级名称。等级共四级，自低到高为：普通会员、银卡会员、金卡会员、钻石会员。
- **F2 等级判定**：等级由累计积分决定，积分达到某一级的门槛即升为该级。各级的积分门槛按运营配置表执行（配置表由运营部门维护，未随本文档下发）。
- **F3 折扣展示**：页面显示当前等级享有的折扣百分比，格式为「本等级折扣：N%」。各级折扣比例同样按运营配置表执行。
- **F4 升级提示**：非最高等级时，页面显示距下一等级还差的积分数；最高等级时显示「已是最高等级」。
- **F5 页面标题**：浏览器标题为「会员中心」。

## 3. 验收要点

- 四个等级名称都能在页面上正确出现，等级名称与折扣文案随积分变化。
- 折扣文案格式与 F3 一致。
- 页面标题与 F5 一致。
